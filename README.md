## 👋 Introduction

Welcome to my personal blog repository!
This project is a static blog site built with **Next.js** and uses **Notion** as a CMS.

It is originally forked from [morethan-log](https://github.com/morethanmin/morethan-log), but I have significantly customized the **UI/UX, styling, and components** to reflect my personal identity as a developer.

## 🎨 Key Customizations

While maintaining the core logic of `morethan-log`, I have focused on the following design & feature improvements:

- **Refined UI Design:** Adopted a dashboard-style layout for better information architecture.
- **Custom Profile Card:** Implemented a unique, IDE-themed profile section using VS Code style syntax highlighting.
- **Styled Components:** Replaced/Enhanced standard CSS with `@emotion/styled` for dynamic theming and better component isolation.
- **Typography & Spacing:** Adjusted global typography and spacing for improved readability.

## 🛠 Tech Stack

- **Framework:** Next.js (React)
- **CMS:** Notion API
- **Styling:** Emotion, Tailwind CSS
- **Deployment:** Vercel
